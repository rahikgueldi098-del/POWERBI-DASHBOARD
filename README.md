## Introduction
This dashboard was created for **Job Seekers, Job Transitioners, and Job Swappers** to solve a common problem: information about the data job market is scattered and hard to grasp. Using a real-world dataset of 2024 data science job postings (including titles, salaries, and locations), this project provides a single, easy-to-use interface to explore market trends and compensation.

## Skills Showcased

- **⚙️ Data Transformation (ETL) with Power Query:**
 Cleaned, shaped, and prepared the raw data for analysis by handling blanks, changing data types, and creating new columns.
 
 - **🧮 Custom Measures & KPIs:**
  Built calculations to uncover key performance indicators such as Median Yearly Salary and Job Count.

- **📊 Core Chart Types:**
 Incorporated Column, Bar, Line, and Area Charts to compare position totals and track changes over time.

- **🗺️ Geospatial Mapping:**
 Utilized Map Charts to display global job distribution patterns.

- **🔢 KPI Cards & Detailed Tables:**
 Displayed key metrics using Cards and provided structured, sortable data through Tables.

- **🎨 Dashboard Layout & Styling:**
 Formatted an intuitive, visually clear layout using diverse chart styles to tell a compelling data narrative.

- **📱 Interactive Features:**

    - **Slicers:** Filters report views dynamically according to Job Title.

    - **Buttons & Bookmarks:** Ensures smooth navigation throughout the dashboard.

   - **Drill-Through:** Enables navigation from high-level overviews down to detailed contextual views.
